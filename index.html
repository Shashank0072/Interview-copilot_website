Why Interview Copilot ?

Invisible is built for interviews, meetings, and focused work — without ever appearing in Zoom, Teams, OBS, or Discord. No cloud. No tracking. No compromises.

Key Features

✅ Runs 100% locally
🫥 Invisible to screen sharing (SetWindowDisplayAffinity)
⚡ Real-time AI streaming [Claude, Grok, Gemini, ChatGPT]
🔒 Encrypted local storage (AES-256)
⌨ Global hotkeys
🚫 No backend server required
👁 Auto-hides during screen sharing
🧠 Notes, chat & templates

How It Works

Electron + Native Windows APIs

Uses native C++ bindings to exclude the app from capture APIs.

Client-Side AI Streaming

Direct Claude API streaming. No proxy, no middleman.

Local Encrypted Storage

SQLite with AES-256 encryption. Nothing leaves your machine.

FAQ

Will Invisible appear in Zoom or OBS?

No. It uses native Windows capture exclusion (WDA_EXCLUDEFROMCAPTURE).

Is my data stored anywhere?

No. All data stays encrypted on your local machine.
